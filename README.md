# Identificador Dactilar

Aplicación Android desarrollada en Java que implementa autenticación biométrica mediante huella dactilar utilizando la API BiometricPrompt.

## Características

- Inicio de sesión mediante huella dactilar.
- Validación biométrica nativa de Android.
- Pantalla de bienvenida después de autenticación exitosa.
- Navegación entre actividades.
- Desarrollo realizado en Android Studio Panda.

## Tecnologías utilizadas

- Java
- Android Studio
- BiometricPrompt
- Android SDK API 26+
